# AdmitOS

An AI platform for international university admissions and scholarships. This repository currently contains the initial frontend shell; all dashboard content is illustrative sample data.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Checks

```bash
npm run lint
npm run build
```

## Routes

- `/` - Dashboard
- `/ai-advisor` - AI Advisor placeholder
- `/universities` - Universities placeholder
- `/scholarships` - Scholarships placeholder
- `/pathways` - Pathways placeholder
- `/applications` - Applications placeholder
- `/profile` - Profile placeholder
